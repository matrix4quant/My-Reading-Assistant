# 阅读助手（my reading assistant）

一个本地运行的桌面书架式语音朗读器。导入你自己的书籍后，双击即可进入朗读页，原书正文与语音逐句同步高亮。软件只朗读导入的原书内容，不生成 AI 摘要、不改写正文。

本人有阅读障碍，更习惯听书，所以做了这个工具希望能帮助到有同样需求的人。这个工具全部由WorkBuddy免费模型完成，如果更新不及时那是因为额度用完了，本人也不会写代码请见谅。

仓库地址：<https://github.com/matrix4quant/My-Reading-Assistant>

## 核心功能

- **书架管理**：导入 `txt / md / epub / pdf`，双击书籍进入朗读页；阅读进度自动保存。
- **语音朗读**：在线 Edge 神经语音（14 种中文音色）与系统语音离线兜底；语速 0.5×～2.5×、音量、音色可调，逐字高亮、自动跟随滚动。
- **三栏阅读**：左侧可收起目录，中间原书正文，右侧可收起书签与笔记栏。
- **书签笔记**：在正文句子上右键加书签、写读书心得；笔记与书签持久化保存。
- **全文搜索**：搜索全书所有章节，结果可连续点击跳转，并可逐级返回跳转前位置。
- **图表查看**：EPUB / PDF 中的图表按正文原位置显示，支持大图滚轮缩放、拖拽平移、适应窗口。
- **文字复制**：正文可选中，支持右键复制所选文字 / 本段文字与 `Ctrl+C`。
- **播放控制**：播放 / 暂停 / 停止 / 上一句 / 下一句、本章时间轴拖动跳转、章节与全书进度显示。
- **在线书库**：首页集成古登堡计划、Open Library、Internet Archive、国家数字图书馆与 Z-Library，支持自定义书库；Z-Library 官方域名自动从公开条目更新。
- **本地化与设置**：菜单、设置窗口、托盘提示随系统语言切换；设置包含书籍库位置、关闭按钮行为（退出 / 最小化到托盘）、关于页版本号。
- **检查更新 / 自动更新**：设置中的「检查更新」或启动时自动检查 GitHub 新版本；确认后自动下载、SHA-256 校验并安装，旧版 exe 保留在本地。
- **免安装分发**：Windows portable 单文件 exe，解压即用。

## 快速开始

1. 从 Releases 下载最新版 `阅读助手 2.2.0.exe`，双击运行，无需安装。
2. 点击首页右上角「＋ 导入书籍」选择本地书籍，双击书封进入朗读页。
3. 以后打开软件会自动检查新版本；也可在「设置 → 通用 → 检查更新」手动检查，确认后自动下载安装。旧版本保留在 exe 同目录。
4. 从源码运行：`npm install` 后 `npm start`；打包：`npm run build`。

> 兼容说明：内部 npm 包名仍为 `bookshelf-reader`，这是为了保持原有数据目录 `…\bookshelf-reader\bookshelf\books` 不变，升级不会丢失书籍、进度、书签或笔记。
